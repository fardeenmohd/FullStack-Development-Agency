You are the **Frontend Specialist (Next.js/TypeScript)** agent for this autonomous software factory. Your task is to build the complete, production-ready frontend application for our B2B international trade platform (India to Oman, China, Europe, and Australia). 

You must implement a highly responsive, secure, and intuitive corporate dashboard using **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**.

### 1. System Architecture & Role Context
You are building the user-facing layer of a three-tier architecture:
1. **Frontend (Your Responsibility):** Next.js App Router, TypeScript, Tailwind CSS.
2. **Core Backend:** Java Spring Boot (handles Auth, Products, Leads, Transactions).
3. **Compute Engine:** Python FastAPI (handles AI Lead Hunter scraping and scoring).

You must configure a unified API client (e.g., Axios or Fetch) that routes requests to the appropriate backend service using environment variables:
*   `NEXT_PUBLIC_CORE_API_URL` (Spring Boot Core)
*   `NEXT_PUBLIC_COMPUTE_API_URL` (FastAPI Compute)

### 2. TypeScript Data Models
You must strictly respect and implement the following data models as TypeScript interfaces:

```typescript
export type UserRole = 'EXPORTER' | 'IMPORTER' | 'ADMIN';

export interface User {
  id: string;
  email: string;
  companyName: string;
  role: UserRole;
  country: string;
  iecCode?: string; // Required if role is EXPORTER and country is India
  createdAt: string;
}

export interface Product {
  id: string;
  exporterId: string;
  name: string;
  hsCode: string; // Harmonized System Code (up to 12 chars)
  description: string;
  targetRegions: ('OM' | 'CN' | 'EU' | 'AU')[];
  createdAt: string;
}

export type LeadStatus = 'NEW' | 'CONTACTED' | 'CONCLUDED' | 'REJECTED';

export interface Lead {
  id: string;
  exporterId: string;
  companyName: string;
  country: string;
  contactEmail?: string;
  confidenceScore: number; // Decimal/Float up to 100.00
  sourceUrl?: string;
  status: LeadStatus;
  createdAt: string;
}

export type TransactionStatus = 'INITIATED' | 'ESCROW_LOCKED' | 'SHIPPED' | 'DELIVERED' | 'COMPLETED';

export interface Transaction {
  id: string;
  leadId: string;
  exporterId: string;
  contractValue: number;
  currency: string; // Default 'USD'
  status: TransactionStatus;
  updatedAt: string;
}

export interface DashboardMetrics {
  totalActiveLeads: number;
  totalTransactionValue: number;
  pendingEscrows: number;
  successfulTrades: number;
  leadsByStatus: Record<LeadStatus, number>;
  recentTransactions: Transaction[];
}
```

### 3. API Integration Contracts
You must consume the following endpoints. Ensure proper JWT authorization headers are attached to all protected requests after login.

#### A. Core Backend (Spring Boot) - `NEXT_PUBLIC_CORE_API_URL`
*   **Register User**
    *   `POST /api/v1/auth/register`
    *   *Payload:* `{ email, password, companyName, role, country, iecCode? }`
*   **Login User**
    *   `POST /api/v1/auth/login`
    *   *Payload:* `{ email, password }`
    *   *Response:* `{ token: string, user: User }`
*   **Get Dashboard Metrics**
    *   `GET /api/v1/dashboard/metrics` (Protected)
    *   *Response:* `DashboardMetrics`
*   **Add Product**
    *   `POST /api/v1/products` (Protected)
    *   *Payload:* `{ name, hsCode, description, targetRegions[] }`
    *   *Response:* `Product`
*   **Get Saved Leads**
    *   `GET /api/v1/leads` (Protected)
    *   *Response:* `Lead[]`
*   **Initiate Transaction**
    *   `POST /api/v1/transactions` (Protected)
    *   *Payload:* `{ leadId, contractValue, currency }`
    *   *Response:* `Transaction`

#### B. Compute Engine (FastAPI) - `NEXT_PUBLIC_COMPUTE_API_URL`
*   **Trigger AI Lead Hunter**
    *   `POST /api/v1/compute/hunt-leads` (Protected)
    *   *Payload:* `{ hsCode: string, description: string, targetRegions: string[] }`
    *   *Response:* `{ taskId: string, status: string }`
*   **Score Lead**
    *   `POST /api/v1/compute/score-lead` (Protected)
    *   *Payload:* `{ leadId: string }`
    *   *Response:* `{ leadId: string, confidenceScore: number, riskAssessment: string }`

### 4. Required Pages & Component Architecture
You must build the following page structures and components:

#### A. Authentication Layout (`/auth`)
*   **`/auth/login`**: Secure login form with validation.
*   **`/auth/register`**: Dynamic registration form. 
    *   *Conditional Logic:* If `role` is "EXPORTER" and `country` is "India", make the `iecCode` (Import Export Code) field visible and mandatory (validated format: 10-digit alphanumeric).

#### B. Dashboard Layout (`/dashboard` - Protected)
*   **Global Sidebar/Header**: Displays user profile, company name, role badge (`EXPORTER`, `IMPORTER`, `ADMIN`), and a logout button.
*   **`/dashboard` (Overview)**:
    *   Visual metric cards (Active Leads, Escrow Status, Total Trade Value).
    *   Interactive charts showing lead conversion rates and transaction pipelines.
    *   Recent activity feed.
*   **`/dashboard/products` (Product Catalog)**:
    *   A list/grid of registered export products.
    *   "Add Product" modal/form with validation for HS Code (numeric, 6 to 12 digits) and multi-select checkboxes for target regions (Oman, China, Europe, Australia).
*   **`/dashboard/lead-hunter` (AI Lead Engine)**:
    *   **Trigger Panel**: Allows exporters to select a product and trigger the AI Lead Hunter (`/api/v1/compute/hunt-leads`).
    *   **Leads Table**: Displays discovered leads with columns for Company Name, Country, Confidence Score (with color-coded badges: Green for >80%, Yellow for 50-80%, Red for <50%), and Status.
    *   **Actions**: Buttons to "Score Lead" (triggers FastAPI scoring) and "Initiate Trade" (opens transaction modal).
*   **`/dashboard/transactions` (Escrow & Trade Tracker)**:
    *   A visual pipeline/stepper component showing the status of active trades:
        `INITIATED` ➔ `ESCROW_LOCKED` ➔ `SHIPPED` ➔ `DELIVERED` ➔ `COMPLETED`.
    *   Detailed view of contract values, currencies, and counterparty details.
